# MB Group — Nueva web corporativa

Web estática responsive de MB Group Importación y Distribución.

## Estructura
- `index.html`: contenidos, secciones y metadatos SEO.
- `styles.css`: diseño y responsive.
- `script.js`: navegación móvil y copyright.
- `assets/`: fotografías y recursos optimizados.

## Publicación
1. Crear un repositorio GitHub, por ejemplo `aburutxaga-star/mbgroup-web`.
2. Subir los archivos **conservando** la estructura de carpetas.
3. En Vercel: Add New → Project → Import Git Repository → `mbgroup-web` → Framework Preset: Other → Deploy.
4. Probar la URL temporal `.vercel.app`.
5. Solo después de aprobar la web, configurar `mbgroupid.com` y `www.mbgroupid.com` en Vercel y actualizar el DNS correspondiente. No cambiar DNS antes de validar.

## Pendiente de validar antes de producción
- Dirección de email `info@mbgroupid.com` (usada provisionalmente como CTA).
- URL oficial de Natur3 (`https://natur3.es/`), antes de enlazarla definitivamente.
- Identidad visual y logo oficiales de MB Group; el logo del sitio es una interpretación tipográfica temporal.
- Fotografías propias de almacén, equipo y operaciones; no se han inventado instalaciones.
- Aviso legal, privacidad y cookies, según datos y obligaciones de la sociedad.
- Textos finales y aprobaciones internas, especialmente claims comerciales.

## Fuente
Textos basados en el dossier interno `mb group.pdf` y contexto corporativo aportado por el usuario. No se incorporan previsiones de facturación ni certificaciones no verificadas.
